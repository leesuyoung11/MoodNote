# moodnote

개인 감정 기록 및 일기 웹사이트입니다.

## 배포
GitHub Pages, Netlify, Vercel 등의 정적 호스팅에 이 폴더의 파일을 그대로 업로드할 수 있습니다.

- `index.html` : 메인 웹사이트
- `manifest.webmanifest` : 모바일 홈 화면/PWA 기본 설정

## 데이터 저장
현재 일기 데이터는 브라우저의 `localStorage`에 저장됩니다.
서버나 데이터베이스에 자동 업로드되지 않습니다.
따라서 브라우저/기기를 바꾸면 기존 기록이 자동으로 동기화되지 않습니다.
사이트 데이터를 삭제하면 기록이 사라질 수 있으므로, 사이트 안의 '백업' 기능을 활용하세요.
